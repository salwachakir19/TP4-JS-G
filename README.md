
# Gestion des commandes "Magasin de cosmétiques"

## 1. Description du projet

Ce projet consiste à créer une application web pour gérer les commandes d'un magasin de cosmétiques. Elle permet de consulter les commandes et de voir les informations des clients et des produits.

Les données sont enregistrées dans des fichiers JSON et utilisées avec JavaScript.

## 2. Structure du projet

Le projet est organisé en plusieurs dossiers et fichiers :

- index.html : la page principale du projet.
- css/style.css : pour le design et les couleurs.
- js : contient les fichiers JavaScript pour gérer les données et l'affichage.
- data/customers.json : contient les informations des clients.
- data/products.json : contient les informations des produits.
- data/orders.json  : contient les informations des commandes.
- README.md : présente le projet et explique comment le lancer.

## 3. Fonctionnalités principales

L'application permet de :

- Afficher la liste des commandes.
- Rechercher un client par son nom.
- Filtrer les commandes par catégorie de produits.
- Filtrer les commandes selon leur statut : Livree, En attente ou Annulee.
- Voir les détails d'une commande, les produits et les quantités.
- Calculer le montant total des commandes.
- Afficher des indicateurs sur les clients, les produits et les commandes.

## 4. Technologies utilisées

- HTML : pour créer la page.
-  CSS et Bootstrap : pour organiser et personnaliser l'interface.
- JavaScript : pour gérer les données, la recherche et les filtres.
- JSON:  pour enregistrer les données des clients, des produits et des commandes.

## 5. Instructions pour lancer le projet

1. Ouvrir le dossier du projet dans Visual Studio Code.
2. Ouvrir le fichier "index.html".
3. Lancer le projet avec l'extension "Live Server".
4. La page s'ouvre dans le navigateur et permet d'utiliser les différentes fonctionnalités.
